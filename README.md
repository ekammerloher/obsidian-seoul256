# Seoul256 for Obsidian

A quiet, low-contrast Obsidian theme inspired by Junegunn Choi's
[seoul256.vim](https://github.com/junegunn/seoul256.vim).

## Design

- Charcoal editor, darker sidebars, and soft gray text.
- Dusty rose titles and headings across all six heading levels.
- Sage tags, list markers, checkboxes, and quote borders.
- Muted cyan links and navigation, with warm cream emphasis.
- Coordinated dark and light palettes, syntax colors, and graph colors.
- Responsive heading sizes, with no external fonts or plugin dependencies.

## Installation

1. Download `manifest.json` and `theme.css`.
2. Place both files in `<vault>/.obsidian/themes/Seoul256/`.
3. In Obsidian, select **Settings > Appearance > Themes > Seoul256**.

The theme follows Obsidian's dark or light appearance setting and preserves
your configured fonts.
